<task type="auto">
  <name>Task 1: Implement CSV builder with semicolon delimiter and BOM prefix</name>
  <files>
    packages/backend/src/report/csv-builder.ts
  </files>
  <action>
    Create `packages/backend/src/report/csv-builder.ts`:

    **Function:** `buildCsv(data: ReportData): string`

    **CSV format requirements:**
    - UTF-8 BOM prefix: `\uFEFF` as the first character (ensures German Excel auto-detects UTF-8)
    - Delimiter: semicolon `;` (German Excel standard — commas collide with German decimal separator)
    - Line endings: `\r\n` (Windows/Excel compatibility)
    - String quoting: double-quote fields that contain semicolons or newlines (defensive)
    - EUR values: use dot as decimal separator in CSV (machine-readable format, NOT German comma format — the CSV is for data import, not display)

    **Columns (superset of PDF — more columns for Steuerberater flexibility):**
    1. Nr (sequential row number)
    2. Symbol
    3. Kaufdatum (buy date — format: yyyy-MM-dd HH:mm:ss or ISO)
    4. Verkaufdatum (sell date — same format)
    5. Menge (amount consumed — raw decimal string)
    6. Einstandswert EUR (cost basis)
    7. Erloes EUR (proceeds)
    8. Gewinn/Verlust EUR (gain/loss)
    9. Gebuehr EUR (fee)
    10. Haltedauer Tage (held days)
    11. Haltefrist erfuellt (Ja/Nein)
    12. Steuerfrei (Ja if haltefrist met, Nein otherwise — explicit column)
    13. Boerse (exchange)

    **Header row:** German labels matching the column list above, separated by semicolons.

    **Data rows:** One row per TradeAppendixRow from data.tradeAppendix.
    - Nr: 1-indexed sequential
    - Haltefrist erfuellt: "Ja" if haltefristMet, "Nein" otherwise
    - Steuerfrei: "Ja" if haltefristMet, "Nein" otherwise (same logic, explicit column name for clarity)
    - All MoneyString values: output as-is (they are already decimal strings like "123.456789")

    **Summary section at the end of CSV (after a blank row):**
    Add summary rows:
    ```
    ;
    Zusammenfassung;
    Steuerjahr;{data.taxYear}
    Spot Netto EUR;{data.spotSummary.netEur}
    Spot Freigrenze;{data.spotSummary.freigrenzeStatus === 'under' ? 'Eingehalten' : 'Ueberschritten'}
    Futures Netto EUR;{data.futuresSummary.netEur}
    Geschaetzte Abgeltungssteuer EUR;{data.futuresSummary.estimatedTaxEur}
    Staking Einkommen EUR;{data.earnSummary.totalIncomeEur}
    ```

    **No external library needed** — manual string building is clean for this flat structure. If a field contains a semicolon (unlikely for numeric data), wrap in double quotes.

    **Helper:** `escapeCsvField(value: string): string` — if value contains `;`, `"`, or `\n`, wrap in double quotes and escape internal quotes by doubling them.
  </action>
  <verify>
    `npm run build -w packages/backend` succeeds.
  </verify>
  <done>
    buildCsv(data) returns a complete CSV string with BOM prefix, semicolon delimiters, German headers, all trade appendix rows, and a summary section.
  </done>
</task>
