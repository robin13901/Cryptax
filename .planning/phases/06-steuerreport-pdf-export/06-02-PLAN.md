Output: `buildPdf(data: ReportData): Promise<Buffer>` function, DejaVu Sans font files, tests.

  <name>Task 1: Install PDFKit, download DejaVu Sans fonts, create PDF builder with cover page and summary sections</name>

  <action>
    **Step 1: Install PDFKit**
    ```
    npm install pdfkit --workspace packages/backend
    npm install --save-dev @types/pdfkit --workspace packages/backend
    ```

    **Step 2: Download DejaVu Sans fonts**
    Download DejaVuSans.ttf and DejaVuSans-Bold.ttf from the official DejaVu Fonts GitHub/SourceForge release. Place them in `packages/backend/src/assets/fonts/`. These fonts are SIL Open Font License, free to bundle. If curl download is difficult, use an npm package like `@fontsource/dejavu-sans` or download from a CDN. The key requirement: TTF files with Latin Extended coverage (ae, oe, ue, ss all render correctly).

    **Step 3: Create `packages/backend/src/report/pdf-builder.ts`**

    CRITICAL: Backend is ESM. PDFKit is CJS. Import using:
    ```typescript
    import { createRequire } from 'module';
    const require = createRequire(import.meta.url);
    const PDFDocument = require('pdfkit');
    ```

    Create a `buildPdf(data: ReportData): Promise<Buffer>` function:

    1. **Document setup:**
       - A4 size (595.28 x 841.89 pts)
       - Margins: 50pt all sides (content width: 495pt)
       - `bufferPages: true` for post-hoc page number injection
       - Register fonts: 'Regular' -> DejaVuSans.ttf, 'Bold' -> DejaVuSans-Bold.ttf
       - Resolve font paths using `import.meta.dirname` + relative path to assets/fonts/

    2. **Cover page** — "Krypto-Steuerreport [Jahr]":
       - Centered title in Bold, large font (~24pt)
       - Subtitle: "Erstellt am [date in dd.MM.yyyy format]"
       - Disclaimer block: "Hinweis: Dieser Report dient ausschliesslich der Dokumentation und stellt keine steuerliche Beratung dar. Bitte konsultieren Sie Ihren Steuerberater."
       - Use crypto-blue (#0070F2) accent line or branding element
       - Add page break after cover

    3. **Anlage SO section** (SpotSummary):
       - Colored header bar (#0070F2 background, white text): "Anlage SO -- Private Veraeusserungsgeschaefte (section 23 EStG)"
       - Key-value pairs: Gesamtgewinn, Gesamtverlust, Netto, Steuerpflichtiger Betrag, Anzahl Trades, Steuerfreie Trades (Haltefrist)
       - Freigrenze status: prominently display "Freigrenze (1.000 EUR): eingehalten / ueberschritten" with color (green #5fdc8a / red #e50000)
       - Format all EUR values in German format (1.234,56 EUR) — create a helper `formatEurPdf(value: string): string` using Intl.NumberFormat('de-DE', { style: 'currency', currency: 'EUR' })

    4. **Anlage KAP section** (FuturesSummary):
       - Colored header bar (#0070F2): "Anlage KAP -- Einkuenfte aus Kapitalvermoegen (section 20 EStG)"
       - Key-value pairs: Gesamtgewinn, Gesamtverlust, Netto, Gebuehren, Steuerpflichtiger Betrag, Geschaetzte Abgeltungssteuer
       - Footnote: "Abgeltungssteuer: 25% + 5,5% Solidaritaetszuschlag = 26,375%"

    5. **Staking/Earn income section** (EarnSummary):
       - Colored header bar (#0070F2): "Einkuenfte aus Staking/Earn (section 22 Nr. 3 EStG)"
       - Total income, record count, Freigrenze status (256 EUR)
       - Per-coin breakdown mini-table: Symbol | Betrag EUR | Anzahl

    6. **Page number injection** (after all content, before doc.end()):
       - Iterate bufferedPageRange, switchToPage, write footer at y=820:
         "Seite X von Y  |  Erstellt: dd.MM.yyyy"
       - Flush pages, then end document.

    7. **Buffer collection:**
       Wrap in Promise: collect chunks on 'data' event, resolve with Buffer.concat on 'end', reject on 'error'.

    **Visual style:** Branded/fintech feel — colored header bars, accent lines, clean spacing. NOT austere Finanzamt style. Use #0070F2 (crypto-blue), #354A5F (crypto-navy), #5fdc8a (green for positive), #e50000 (red for losses).

    **Important:** Do NOT build the trade appendix table in this plan. That is plan 06-03. This plan builds the cover + three summary sections only. Export the helper functions (sectionHeader, formatEurPdf, keyValueLine) so 06-03 can import them.
  </action>
  <verify>

    `import { buildPdf } from './report/pdf-builder.js'` resolves in TypeScript.
  </verify>
  <done>
    buildPdf(data) produces a Buffer containing a multi-page PDF with cover page, Anlage SO section, Anlage KAP section, and Staking/Earn section. German characters render correctly via embedded DejaVu Sans TTF. Page numbers are injected in footers.
  </done>
