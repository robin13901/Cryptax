  <action>
    **ReportTab.tsx — top-level container:**

    State:
    - `availableYears: number[]` — from GET /api/report/years
    - `selectedYear: number` — default to most recent year
    - `reportData: ReportData | null` — from GET /api/report/:year/preview
    - `loading: boolean` — true while fetching preview
    - `downloading: 'pdf' | 'csv' | null` — tracks which download is in progress

    On mount:
    - Fetch GET /api/report/years to populate year selector
    - Auto-select most recent year

    On year change:
    - Fetch GET /api/report/{year}/preview
    - Set reportData from JSON response (or null on 404)

    Layout:
    - Header area: "Steuerreport" title + YearSelector (reuse from Dashboard/YearSelector.tsx — same component, import it)
    - Action buttons area: Two buttons side by side:
      - "PDF herunterladen" (disabled if no data or downloading)
      - "CSV exportieren" (disabled if no data or downloading)
    - Preview area: <ReportPreview data={reportData} /> or empty state

    Download handlers:
    - `downloadPdf()`: fetch /api/report/{year}/pdf, get blob, create object URL, trigger anchor click, revoke URL. Set downloading='pdf' during fetch, clear on complete.
    - `downloadCsv()`: same pattern with /api/report/{year}/csv and filename "cryptax-steuerberater-{year}.csv"

    Empty state (when reportData is null and not loading):
    - GlassSurface wrapper
    - Icon + message: "Keine Daten fuer [year]. Bitte zuerst Transaktionen importieren und die Steuerberechnung ausfuehren."
    - Style similar to the existing empty state in App.tsx

    Loading state:
    - Show a simple "Lade Report..." text or spinner while fetching preview

    **ReportPreview.tsx — renders ReportData as HTML:**

    Props: `{ data: ReportData }`

    Single continuous scroll page with sections:

    1. **Report header:** "Krypto-Steuerreport {year}" with generation date
    2. **Anlage SO section** (wrapped in GlassSurface):
       - Title: "Anlage SO — Private Veraeusserungsgeschaefte (section 23 EStG)"
       - Key-value grid: Gesamtgewinn, Gesamtverlust, Netto, Steuerpflichtiger Betrag
       - Freigrenze status: prominently displayed with color (green/red)
       - Trade count: "X Transaktionen (davon Y steuerfrei)"
    3. **Anlage KAP section** (GlassSurface):
       - Title: "Anlage KAP — Einkuenfte aus Kapitalvermoegen (section 20 EStG)"
       - Key-value grid: Gesamtgewinn, Gesamtverlust, Netto, Gebuehren, Geschaetzte Abgeltungssteuer
       - Footnote: "25% + 5,5% Soli = 26,375%"
    4. **Staking/Earn section** (GlassSurface):
       - Title: "Einkuenfte aus Staking/Earn (section 22 Nr. 3 EStG)"
       - Total income, record count, Freigrenze status
       - Per-coin breakdown table (if available)
    5. **Trade appendix** (GlassSurface):
       - Title: "Handelsanhang — Alle Transaktionen"
       - HTML table with columns matching PDF: Symbol, Kaufdatum, Verkaufdatum, Menge, Einstandswert, Erloes, G/V, Tage, Haltefrist
       - Scrollable container (overflow-x: auto for smaller screens)
       - Alternating row colors
       - Gain/loss color: green/red
       - Haltefrist "Ja" in green

    Use existing format utilities: `formatEur()`, `formatNumber()` from `../../utils/format.ts`.
    Use `gainLossColor()` for conditional coloring.

    **CSS Styling:**
    - Follow glassmorphism design system (GlassSurface wrappers, CSS custom properties)
    - Section headers with crypto-blue accent
    - Key-value pairs in a CSS grid (label left, value right)
    - Table styles: sticky header, alternating rows, compact font size
    - Download buttons: primary (crypto-blue) and secondary styles
    - Responsive: stack buttons vertically on narrow screens
