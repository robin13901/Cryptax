  <name>Task 1: Create report routes and register in index.ts</name>
  <files>
    packages/backend/src/routes/report.ts

  </files>
  <action>
    **Create `packages/backend/src/routes/report.ts`:**

    Follow the exact pattern of `routes/summary.ts` — export `registerReportRoutes(app: Hono)`.

    **Route 1: GET /api/report/years**
    - Query: `SELECT DISTINCT tax_year FROM tax_summaries ORDER BY tax_year`
    - Return: `{ years: number[] }`
    - If no tax_summaries exist: return `{ years: [] }`

    **Route 2: GET /api/report/:year/preview**
    - Parse year param, validate (return 400 if NaN)
    - Instantiate ReportGenerator, call generate(year)
    - If null (no data): return 404 `{ error: "Keine Daten fuer das Jahr [year]" }`
    - If data: return 200 with ReportData JSON

    **Route 3: GET /api/report/:year/pdf**
    - Parse year param, validate (return 400 if NaN)
    - Instantiate ReportGenerator, call generate(year)
    - If null: return 404
    - Call `buildPdf(data)` (await — it returns Promise<Buffer>)
    - Set headers:
      - `Content-Type: application/pdf`
      - `Content-Disposition: attachment; filename="cryptax-steuerreport-{year}.pdf"`
    - Return `c.body(pdfBuffer)` — do NOT stream, return the collected Buffer

    **Route 4: GET /api/report/:year/csv**
    - Parse year param, validate (return 400 if NaN)
    - Instantiate ReportGenerator, call generate(year)
    - If null: return 404
    - Call `buildCsv(data)` (synchronous — returns string)
    - Set headers:
      - `Content-Type: text/csv; charset=utf-8`
      - `Content-Disposition: attachment; filename="cryptax-steuerberater-{year}.csv"`
    - Return `c.body(csvString)`

    **Shared logic:** Extract a `getReportData(c, year)` helper that handles param validation and ReportGenerator instantiation to avoid code duplication across the 3 year-based routes.

    **Update `packages/backend/src/index.ts`:**
    - Add import: `import { registerReportRoutes } from './routes/report.js';`
    - Add call: `registerReportRoutes(app);` after `registerTransactionRoutes(app);`
  </action>
  <verify>
    `npm run build -w packages/backend` succeeds.
    `curl http://localhost:3001/api/report/years` returns JSON (if dev server running).
  </verify>
  <done>
    Four report API endpoints registered and wired into the Hono app. Preview returns JSON, PDF returns binary with correct headers, CSV returns text with correct headers, years returns available years.
  </done>
</task>
