<task type="auto">
  <name>Task 2: Implement ReportGenerator class with tests</name>
  <files>
    packages/backend/src/engine/report-generator.ts

  <action>
    Create `packages/backend/src/engine/report-generator.ts`:

    **Class: ReportGenerator**
    - Constructor takes the Drizzle db instance (same pattern as existing engine code — import `db` from '../db/client.js')
    - Method: `generate(taxYear: number): ReportData | null`

    **generate() logic:**

    1. **Check data exists:** Query `SELECT 1 FROM tax_summaries WHERE tax_year = ?`. If empty, return null.

    2. **Build SpotSummary:** Query tax_summaries WHERE bucket='private_sale' AND tax_year=year.
       - Map totalGainsEur, totalLossesEur, netEur, taxableAmountEur from the row.
       - freigrenzeStatus: parseFloat(netEur) <= 1000 ? 'under' : 'over'
       - taxFreeTradeCount: query lot_consumptions WHERE tax_year=year AND haltefrist_met=1, count distinct sell_transaction_id.
       - Use TAX_CONSTANTS.SPOT_FREIGRENZE_EUR for the limit.

    3. **Build FuturesSummary:** Query tax_summaries WHERE bucket='futures_pnl' AND tax_year=year.
       - totalFeesEur: SUM(fee_eur) from futures_positions WHERE tax_year=year.
       - Map remaining fields from tax_summaries row.

    4. **Build EarnSummary:** Query tax_summaries WHERE bucket='staking_earn' AND tax_year=year.
       - totalIncomeEur: SUM(eur_value_at_receipt) from earn_income WHERE tax_year=year.
       - freigrenzeStatus: parseFloat(totalIncomeEur) <= 256 ? 'under' : 'over'
       - perCoinBreakdown: GROUP BY symbol from earn_income, sum eur_value_at_receipt, count records.
       - Use TAX_CONSTANTS.EARN_FREIGRENZE_EUR for the limit.

    5. **Build TradeAppendix:** Query lot_consumptions JOIN fifo_lots (for symbol, acquired_at) JOIN transactions (for traded_at, exchange) WHERE lot_consumptions.tax_year=year.
       - Map each row to TradeAppendixRow.
       - buyDate = fifo_lots.acquired_at, sellDate = transactions.traded_at.
       - Sort by sellDate ASC, then symbol ASC.
       - Include ALL consumptions (both haltefristMet=true and false).

    6. **Handle missing buckets gracefully:** If a bucket has no tax_summaries row for the year, return zero-valued summary for that bucket (the engine may not have generated data for that bucket if there were no transactions of that type).

    **Tests** (`report-generator.test.ts`):
    - Use the same in-memory SQLite + full migrations pattern from `golden-master.test.ts`.
    - Test: generate() returns null for a year with no data.
    - Test: generate() returns correct SpotSummary for a year with spot trades.
    - Test: generate() returns correct FuturesSummary with Abgeltungssteuer calculation.
    - Test: generate() returns correct EarnSummary with per-coin breakdown.
    - Test: tradeAppendix includes both haltefrist-met (tax-free) and non-met rows.
    - Test: tradeAppendix is sorted by sell date then symbol.
    - Test: missing bucket returns zero-valued summary (not null/undefined).
    - Seed test data by directly inserting into the DB tables (transactions, fifo_lots, lot_consumptions, futures_positions, earn_income, tax_summaries).
  </action>
