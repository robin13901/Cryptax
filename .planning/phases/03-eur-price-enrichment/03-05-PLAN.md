    **1. Create shared price types** in `packages/shared/src/types/price.ts`:
    ```typescript
    export interface PriceStatusResponse {
      total: number;
      resolved: number;
      unresolved: number;
      bySource: Record<string, number>;
      failureBreakdown: Record<string, number>;  // reason -> count
      unresolvedTransactions: Array<{
        id: number;
        symbol: string;
        tradedAt: string;
        failureReason: string | null;
      }>;
    }

    export interface EnrichmentResponse {
      total: number;
      resolved: number;
      failed: number;
      bySource: Record<string, number>;
      failures: Array<{ transactionId: number; symbol: string; reason: string }>;
    }

    export interface ManualPriceEntry {
      transactionId: number;
      eurPrice: string;
    }
    ```
    Export these from `packages/shared/src/index.ts`.

    **2. Create `packages/backend/src/routes/prices.ts`** with `registerPriceRoutes(app)`:

    **GET /api/prices/status:**
    - Query transactions table for counts:
      - total: COUNT(*)
      - resolved: COUNT(*) WHERE eur_price IS NOT NULL
      - unresolved: COUNT(*) WHERE eur_price IS NULL
    - Group by price_source for bySource breakdown
    - Group by price_failure_reason for failureBreakdown
    - Select unresolved transactions (id, symbol, traded_at, price_failure_reason) for the unresolvedTransactions list
    - Return PriceStatusResponse

    **POST /api/prices/enrich:**
    - Create Bitget + CoinGecko clients (with real fetch, throttled)
    - Call `runEnrichment(db, deps)` — NOT streaming, just run to completion
    - Return EnrichmentResponse with final counts
    - Wrap in try-catch, return 500 with error message on failure

    **GET /api/prices/enrich/progress:**
    - Uses `streamSSE` from `hono/streaming`
    - Creates clients, calls `runEnrichment(db, deps, onProgress)` where onProgress writes SSE events:
      ```typescript
      await stream.writeSSE({
        data: JSON.stringify(progress),
        event: 'progress',
        id: String(progress.processed),
      });
      ```
    - Final SSE event: `{ event: 'complete', data: JSON.stringify(result) }`
    - Note: only ONE enrichment should run at a time. Use a simple module-level `let isRunning = false` guard. Return 409 if already running.

    **PATCH /api/prices/manual:**
    - Accepts `ManualPriceEntry` body: `{ transactionId, eurPrice }`
    - Validate: transactionId exists, eurPrice is valid Decimal string, transaction is currently unresolved (eur_price IS NULL)
    - Update: SET eur_price = eurPrice, price_source = 'manual', price_resolved_at = now, price_failure_reason = NULL
    - Return updated transaction summary
    - Return 400 if transaction already has a non-manual resolved price (users can only manually set UNRESOLVED transactions per CONTEXT decision)

    **3. Register routes** in `packages/backend/src/index.ts`:
    - Import `registerPriceRoutes` and call it: `registerPriceRoutes(app);`

    **4. Auto-trigger enrichment after import** in `packages/backend/src/routes/import.ts`:
    - After the `Promise.all(files.map(...))` succeeds and BEFORE returning the response, fire-and-forget `runEnrichment(db, deps)`. Do NOT await it — the import response should return immediately.
    - Use: `runEnrichment(db, deps).catch(err => console.error('[prices] Auto-enrichment failed:', err));`
    - This means enrichment starts in the background after import completes. The frontend will poll /status or connect to /progress to track it.

    **5. Tests** in `packages/backend/src/routes/prices.test.ts`:
    - GET /api/prices/status: returns correct counts with mock data in in-memory DB
    - POST /api/prices/enrich: returns enrichment result (mock the enrichment engine)
    - PATCH /api/prices/manual: updates unresolved transaction; rejects already-resolved
    - 409 guard: second concurrent POST /enrich returns 409

    Run `npx biome format --write` and `npx vitest run`.
