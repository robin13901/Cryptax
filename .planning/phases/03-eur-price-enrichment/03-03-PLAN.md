<objective>
Build the CoinGecko historical price client — the fallback price source for coins not listed on Bitget (delisted or obscure tokens).

Purpose: CoinGecko is the last resort for price resolution when Bitget has no data. It provides daily-granularity EUR prices. The client needs its own rate limit (30 req/min), a symbol-to-CoinGecko-ID mapping, and clear error handling for the 365-day free-tier limitation.

Output: Tested `fetchCoinGeckoPrice` and `loadCoinGeckoSymbolMap` with mocked HTTP, p-throttle wrapped.
</objective>

  <files>packages/backend/src/prices/coingecko-client.ts, packages/backend/src/prices/coingecko-client.test.ts</files>
  <behavior>
    fetchCoinGeckoPrice(coinId, utcMs, fetchFn?) -> string | null
    - Throws CoinGeckoOutOfRangeError for 365-day limit

    Cases:
    - ("bitcoin", 1717200000000) -> "92254.82" (EUR price as Decimal string)
    - ("bitcoin", oldTimestamp) -> throws CoinGeckoOutOfRangeError (error_code 10012)
    - ("nonexistent-coin", utcMs) -> null (no market_data in response)
    - ("bitcoin", utcMs) when rate limited (429) -> null
    - ("bitcoin", utcMs) when network error -> null

    loadCoinGeckoSymbolMap(fetchFn?) -> Map&lt;string, string&gt;
    - Fetches /api/v3/coins/list, builds lowercase symbol -> id map
    - ("btc" -> "bitcoin", "eth" -> "ethereum", ...)

    Cases:
    - Normal response -> Map with entries
    - Network error -> throws (caller must handle — this is a startup operation)
    - Empty response -> empty Map

    createCoinGeckoClient(fetchFn?) -> { fetchPrice, loadSymbolMap }
    - Wraps fetchCoinGeckoPrice with p-throttle({ limit: 1, interval: 2000 })
    - loadSymbolMap is NOT throttled (single call, run once at enrichment start)
  </behavior>
  <implementation>
    1. Create coingecko-client.ts:
       - `COINGECKO_BASE = 'https://api.coingecko.com/api/v3'`

       - `class CoinGeckoOutOfRangeError extends Error` — thrown when API returns code 10012 (exceeds 365-day free tier limit). Callers catch this to set priceFailureReason = 'coingecko-miss'.

       - `fetchCoinGeckoPrice(coinId, utcMs, fetchFn = globalThis.fetch)`:
         - Format date as DD-MM-YYYY from UTC ms
         - GET `/coins/{coinId}/history?date={dateStr}&localization=false`
         - Parse response: check for `error.status.error_code === 10012` — throw CoinGeckoOutOfRangeError
         - Extract `market_data.current_price.eur`
         - Convert to string using `new Decimal(eur).toString()` (avoid float formatting)
         - Return null if market_data or current_price or eur is missing
         - 429 status → return null (p-throttle should prevent this, but defensive)
         - Network error → return null (never throw except for CoinGeckoOutOfRangeError)

       - `loadCoinGeckoSymbolMap(fetchFn = globalThis.fetch)`:
         - GET `/coins/list`
         - Response: array of `{ id, symbol, name }`
         - Build `Map<string, string>` from `symbol.toLowerCase()` → `id`
         - For duplicate symbols, keep the FIRST entry (CoinGecko lists most popular first)
         - Cache the map — this function should be called ONCE per enrichment run

       - `SYMBOL_OVERRIDES: Record<string, string>`:
         - Manual override map for known ambiguous symbols from Bitget
         - Start with: `{ "comp": "compound-governance-token" }` (example)
         - Applied BEFORE the dynamic map lookup

       - `createCoinGeckoClient(fetchFn?)`:
         - Returns `{ fetchPrice: throttled, loadSymbolMap }`
         - fetchPrice wrapped with `pThrottle({ limit: 1, interval: 2000 })`

    2. Tests mock fetch for all scenarios:
       - Successful price fetch → returns Decimal string
       - Out-of-range error (code 10012) → throws CoinGeckoOutOfRangeError
       - Missing market_data → returns null
       - 429 rate limit → returns null
       - Network error → returns null
       - Date formatting: verify DD-MM-YYYY format (not YYYY-MM-DD)
       - Symbol map: normal load returns Map with correct entries
       - Symbol map: duplicate symbols keep first entry
       - Symbol map: SYMBOL_OVERRIDES take priority over dynamic map

    Run `npx biome format --write` on new files. Then run `npx vitest run`.
  </implementation>
</feature>
