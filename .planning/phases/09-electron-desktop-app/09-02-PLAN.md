  <name>Task 1: Create packages/electron workspace with package.json and install dependencies</name>
  <files>packages/electron/package.json, package.json, tsconfig.json</files>
  <action>
1. Create `packages/electron/` directory.

2. Create `packages/electron/package.json`:
```json
{
  "name": "@cryptax/electron",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "main": "./out/main/index.js",
  "scripts": {
    "dev": "electron-vite dev",
    "build": "electron-vite build",
    "package": "electron-vite build && electron-builder",
    "make:win": "electron-vite build && electron-builder --win --x64",
    "postinstall": "electron-builder install-app-deps"
  },
  "dependencies": {
    "@cryptax/backend": "*",
    "@cryptax/shared": "*",
    "@hono/node-server": "^1.19.11"
  },
  "devDependencies": {
    "@electron/rebuild": "^3.7.1",
    "@types/node": "^24.12.0",
    "@vitejs/plugin-react": "^6.0.0",
    "electron": "^41.1.0",
    "electron-builder": "^25.1.8",
    "electron-vite": "^3.1.0",
    "typescript": "~5.9.3",
    "vite": "^8.0.0"
  }
}
```

NOTE on electron-vite version: The research says v5.x but check the actual latest on npm. If electron-vite ^5.x is not available, use the latest stable (^3.x or ^2.x). The API (`defineConfig`, `externalizeDepsPlugin`) is stable across versions. Use `npm view electron-vite versions` to verify.

NOTE on electron version: Use `^41.1.0` as specified in research. If install fails (not yet released), fall back to the latest available stable (`npm view electron version`).

3. The root `package.json` already has `"workspaces": ["packages/*"]` which will automatically pick up `packages/electron`. No change needed to root package.json workspaces.

4. Update root `tsconfig.json` to add the electron reference:
```json
{
  "compilerOptions": {
    "strict": true,
    "target": "ES2022"
  },
  "files": [],
  "references": [
    { "path": "./packages/shared" },
    { "path": "./packages/backend" },
    { "path": "./packages/frontend" },
    { "path": "./packages/electron" }
  ]
}
```

5. Create `packages/electron/tsconfig.json`:
```json
{
  "extends": "../../tsconfig.json",
  "compilerOptions": {
    "composite": true,
    "module": "ESNext",
    "moduleResolution": "bundler",
    "outDir": "./out",
    "rootDir": "./src",
    "skipLibCheck": true,
    "declaration": true,
    "declarationMap": true,
    "types": ["node"]
  },
  "include": ["src/**/*.ts"],
  "references": [
    { "path": "../shared" },
    { "path": "../backend" }
  ]
}
```

NOTE: Use `"moduleResolution": "bundler"` (not `"NodeNext"`) because electron-vite processes the source through Vite/Rollup which uses bundler resolution. This avoids `.js` extension requirements in imports within the electron package.

6. Create placeholder source directories so TypeScript doesn't complain:
- `packages/electron/src/main/` (empty dir, will be populated in Plan 03)
- `packages/electron/src/preload/` (empty dir, will be populated in Plan 03)

7. Run `npm install` from the project root to install all new dependencies and link workspaces.

IMPORTANT: If `npm install` fails due to version resolution (electron or electron-vite), adjust versions to the latest available stable. Use `npm view electron version` and `npm view electron-vite version` to check.

IMPORTANT: The `postinstall` script runs `electron-builder install-app-deps` which triggers native module rebuilds. This may take a minute on first install. If it fails, check that build tools are available (Visual Studio Build Tools on Windows).

<task type="auto">
  <name>Task 2: Create electron-vite config and electron-builder.yml</name>
  <files>packages/electron/electron.vite.config.ts, packages/electron/electron-builder.yml</files>
  <action>
1. Create `packages/electron/electron.vite.config.ts`:

```typescript
import { defineConfig, externalizeDepsPlugin } from 'electron-vite';
import react from '@vitejs/plugin-react';
import { resolve } from 'node:path';

export default defineConfig({
  main: {
    plugins: [externalizeDepsPlugin()],
    build: {
      outDir: 'out/main',
      rollupOptions: {
        external: ['better-sqlite3'],
        input: { index: resolve(__dirname, 'src/main/index.ts') },
      },
    },
  },
  preload: {
    plugins: [externalizeDepsPlugin()],
    build: {
      outDir: 'out/preload',
      rollupOptions: {
        input: { index: resolve(__dirname, 'src/preload/index.ts') },
      },
    },
  },
  renderer: {
    root: resolve(__dirname, '../frontend'),
    build: {
      outDir: resolve(__dirname, 'out/renderer'),
      rollupOptions: {
        input: { index: resolve(__dirname, '../frontend/index.html') },
      },
    },
    plugins: [react()],
    server: {
      port: 5174,
      proxy: {
        '/api': { target: 'http://localhost:3001', changeOrigin: true },
      },
    },
  },
});
```

NOTE: If `electron-vite` does not export `externalizeDepsPlugin` (API may differ by version), check the installed version's docs. For electron-vite v2.x, the plugin may be imported differently or may need to be replaced with manual `external` config in rollupOptions. Adapt accordingly.

NOTE: `__dirname` works in the config file because electron-vite processes configs in Node.js CJS context. If it doesn't work (ESM config), use `import.meta.dirname` (Node 22+) or `dirname(fileURLToPath(import.meta.url))`.

2. Create `packages/electron/electron-builder.yml`:

```yaml
appId: com.cryptax.app
productName: Cryptax
copyright: Copyright 2026

directories:
  output: dist-installer
  buildResources: build-resources

# Drizzle SQL migration files must live outside asar (read by fs at runtime)
extraResources:
  - from: ../backend/drizzle
    to: drizzle
    filter:
      - "**/*.sql"
      - "**/meta/*.json"

# Native .node files must NOT be inside asar
asarUnpack:
  - "**/*.node"
  - "**/node_modules/better-sqlite3/**"

# Rebuild native modules against Electron's ABI
npmRebuild: true

files:
  - out/**/*
  - package.json

win:
  target:
    - target: nsis
      arch:
        - x64

nsis:
  oneClick: false
  allowToChangeInstallationDirectory: true
  perMachine: false
  createDesktopShortcut: true
  createStartMenuShortcut: true

# Optional: add icon later
# icon: build-resources/icon.png
```

3. Create the `packages/electron/build-resources/` directory (empty for now — icons added later).

4. Add `.gitignore` entries in `packages/electron/.gitignore`:
```
out/
dist-installer/
```
