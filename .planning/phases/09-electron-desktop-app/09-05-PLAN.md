<task type="auto">
  <name>Task 1: Build and package the Windows NSIS installer</name>
  <files>packages/electron/electron-builder.yml, packages/electron/package.json</files>
  <action>
1. First, verify the electron-vite build step works:
```bash
cd packages/electron
npm run build
```
This should produce:
- `out/main/index.js` (bundled main process)
- `out/preload/index.js` (bundled preload)
- `out/renderer/index.html` + assets (bundled frontend)

If the build fails, diagnose and fix:
- Missing dependencies: install them
- Import resolution: adjust electron.vite.config.ts aliases
- TypeScript errors: fix type issues

2. Verify the output structure:
```bash
ls -la packages/electron/out/main/
ls -la packages/electron/out/preload/
ls -la packages/electron/out/renderer/
```

3. Run electron-builder to create the installer:
```bash
cd packages/electron
npx electron-builder --win --x64
```

Or use the package.json script:
```bash
npm run make:win -w packages/electron
```

4. Common issues to fix during packaging:

a) **better-sqlite3 ABI mismatch during packaging**: If npmRebuild fails:
   ```bash
   cd packages/electron
   npx @electron/rebuild -f -w better-sqlite3
   ```
   Then retry `electron-builder`.

b) **Missing files in output**: If electron-builder can't find `out/` directory, verify `files` patterns in electron-builder.yml match the actual output structure.

c) **Monorepo node_modules resolution**: electron-builder may not find hoisted dependencies. If so, add explicit file patterns:
   ```yaml
   files:
     - out/**/*
     - package.json
     - "!node_modules/**"  # Let electron-builder handle deps
   ```

   Or if native modules are missed, add:
   ```yaml
   files:
     - out/**/*
     - package.json
     - node_modules/better-sqlite3/**
   ```

d) **extraResources path**: If the drizzle migration files aren't found, verify the relative path `../backend/drizzle` is correct relative to `packages/electron/`.

e) **App icon**: If electron-builder warns about missing icon, create a minimal placeholder or add `"icon": false` to suppress the warning for now.

f) **Version mismatch**: Ensure `packages/electron/package.json` has a valid semver `version` field (e.g., "1.0.0") — electron-builder uses this for the installer filename.

5. After successful build, verify the output:
```bash
ls -la packages/electron/dist-installer/
```
Should contain a `.exe` installer file.

6. Verify the packaged app structure (without installing):
```bash
# List the contents of the generated resources to verify migration files
# The unpacked asar should have better-sqlite3 outside
```

7. Update `packages/electron/package.json` version to "1.0.0" if still at "0.0.0" (electron-builder needs a real version).

8. Ensure `packages/electron/dist-installer/` is in `.gitignore` (should already be from Plan 02).
  </action>
