**CategoryBadge.tsx:**

Small pill-shaped badge showing the transaction category. Props:
- `type: CanonicalType` (from @cryptax/shared)

Map canonical types to display categories:
- `buy`, `sell` -> "Spot" (blue, #0070F2)
- `futures_open_long`, `futures_open_short`, `futures_close_long`, `futures_close_short`, `futures_funding` -> "Futures" (purple, #a78bfa)
- `earn_deposit`, `earn_interest`, `earn_withdrawal` -> "Earn" (green, #5fdc8a)
- `fee`, `futures_fee` -> "Fee" (orange, #E9730C)
- `transfer_in`, `transfer_out` -> "Transfer" (gray, rgba(255,255,255,0.4))
- `unknown` -> "Sonstige" (gray)

CSS: `.category-badge` — display: inline-flex, padding: 0.15rem 0.5rem, border-radius: 4px, font-size: 0.7rem, font-weight: 600, letter-spacing: 0.02em, text-transform: uppercase. Background uses the color at 20% opacity, text uses the color at full.

**TransactionRow.tsx:**

Single row in the transaction table. Props:
- `tx: TransactionListItem`
- `isSelected: boolean`
- `onClick: () => void`

Renders a table row `<tr>` with columns:
1. Date — `new Date(tx.tradedAt).toLocaleDateString('de-DE')` + time in smaller text
2. Coin — `tx.symbol`
3. Typ — `<CategoryBadge type={tx.canonicalType} />`
4. Richtung — `tx.side ?? '--'` (Buy/Sell)
5. Menge — `formatNumber(tx.amount, 6)` (6 decimals for crypto amounts)
6. EUR Wert — `tx.eurPrice ? formatEur(parseFloat(tx.eurPrice) * parseFloat(tx.amount)) : '--'`
7. Gebuehr — `formatNumber(tx.fee, 6)`

Add hover state (slightly brighter background) and selected state (blue border-left or background tint).

Each change calls `onFilterChange` with updated state. The parent (TransactionList) converts FilterState to API query params.

**TransactionList.tsx:**

Main transaction list component with infinite scroll, sorting, and filter integration.

State:
- `transactions: TransactionListItem[]` — accumulated list (grows on scroll)
- `total: number` — total count from API
- `hasMore: boolean` — from API response
- `loading: boolean`
- `filters: FilterState` — from TransactionFilters
- `sortBy: string` — default "tradedAt"
- `sortDir: 'asc' | 'desc'` — default "desc"
- `offset: number` — current pagination offset
- `selectedId: number | null` — for detail view (plan 07)

Implementation:

1. **Fetch function** (`loadTransactions`):
   ```typescript
   const params = new URLSearchParams();
   if (filters.year) params.set('year', filters.year);
   if (filters.type) params.set('type', mapTypeFilter(filters.type)); // map "Spot" -> "buy,sell" etc
   if (filters.coin) params.set('coin', filters.coin);
   if (filters.dateFrom) params.set('from', filters.dateFrom);
   if (filters.dateTo) params.set('to', filters.dateTo);
   if (filters.search) params.set('search', filters.search);
   params.set('sortBy', sortBy);
   params.set('sortDir', sortDir);
   params.set('limit', '50');
   params.set('offset', String(offset));

   const res = await fetch(`/api/transactions?${params}`);
   const page: TransactionPageResponse = await res.json();
   ```

2. **Type filter mapping:** The UI shows "Spot" but the API accepts canonicalType values. Map:
   - "Spot" -> type=buy (also includes sell — or handle server-side with a group param)
   - Actually, the simplest approach: pass the type filter as `type` param directly if it's a single canonicalType. For category groups (Spot = buy+sell), either:
     a. Make multiple calls (complex), or
     b. Add a `category` param to the API that maps to multiple types (preferred — but this was not in plan 02)
   - For now: use type filter as direct canonicalType filter. The dropdown shows the individual types: buy, sell, earn_interest, futures_close_long, etc. Group labels in the dropdown using `<optgroup>`.

3. **Initial load:** `useEffect` on mount and on filter/sort change — reset `offset=0`, clear transactions, fetch first page.

4. **Load more (infinite scroll):**
   ```tsx
   const sentinelRef = useRef<HTMLDivElement>(null);

   useEffect(() => {
     const observer = new IntersectionObserver(
       (entries) => {
         if (entries[0].isIntersecting && hasMore && !loading) {
           setOffset(prev => prev + 50);
         }
       },
       { threshold: 0.1 }
     );
     if (sentinelRef.current) observer.observe(sentinelRef.current);
     return () => observer.disconnect();
   }, [hasMore, loading]);
   ```
   When offset changes, fetch next page and APPEND to existing transactions array.

5. **Sort:** Clickable column headers. Clicking toggles asc/desc (default desc for date, asc for alpha). On sort change, reset offset=0, clear list, re-fetch.
   - Sort indicator: arrow icon (Unicode ▲/▼) next to active column header

6. **Render:**
   ```tsx
   <div className="transaction-list">
     <TransactionFilters filters={filters} onFilterChange={handleFilterChange} />
     <div className="transaction-list__count">
       {total} Transaktionen
     </div>
     <div className="transaction-list__table-wrapper">
       <table className="transaction-list__table">
         <thead>
           <tr>
             <th onClick={() => handleSort('tradedAt')}>Datum {sortIndicator('tradedAt')}</th>
             <th onClick={() => handleSort('symbol')}>Coin {sortIndicator('symbol')}</th>
             <th>Typ</th>
             <th>Richtung</th>
             <th onClick={() => handleSort('amount')}>Menge {sortIndicator('amount')}</th>
             <th onClick={() => handleSort('eurPrice')}>EUR Wert {sortIndicator('eurPrice')}</th>
             <th>Gebuehr</th>
           </tr>
         </thead>
         <tbody>
           {transactions.map(tx => (
             <TransactionRow
               key={tx.id}
               tx={tx}
               isSelected={tx.id === selectedId}
               onClick={() => setSelectedId(tx.id)}
             />
           ))}
         </tbody>
       </table>
     </div>
     {loading && <div className="transaction-list__loading">Laden...</div>}
     <div ref={sentinelRef} style={{ height: 1 }} />
   </div>
   ```
