**TransactionDetail.tsx:**

Slide-in side panel using `motion/react` AnimatePresence pattern. Props:
- `transactionId: number | null` — null means panel closed
- `onClose: () => void`
- `onNavigate: (direction: 'prev' | 'next') => void`

State:
- `detail: TransactionDetailResponse | null`
- `loading: boolean`

Implementation:

1. **Fetch on id change:**
   ```tsx
   useEffect(() => {
     if (!transactionId) return;
     setLoading(true);
     fetch(`/api/transactions/${transactionId}`)
       .then(res => res.json())
       .then((data: TransactionDetailResponse) => {
         setDetail(data);
         setLoading(false);
       })
       .catch(() => setLoading(false));
   }, [transactionId]);
   ```

2. **Slide-in animation:**
   ```tsx
   <AnimatePresence>
     {transactionId !== null && (
       <motion.div
         key="detail-panel"

         animate={{ opacity: 1 }}
         exit={{ opacity: 0 }}
       >
         <motion.aside
           className="transaction-detail"
           initial={{ x: '100%' }}
           animate={{ x: 0 }}
           exit={{ x: '100%' }}
           transition={{ duration: 0.3, ease: 'easeOut' }}

           <GlassSurface width="100%" height="100%" borderRadius={0} backgroundOpacity={0.18}>
   ```

**TransactionList.tsx updates:**

1. Import TransactionDetail and AnimatePresence
2. Add `onNavigate` handler that moves selectedId to prev/next in the current transactions array
3. Render TransactionDetail component at the end of TransactionList:
   ```tsx
   <TransactionDetail
     transactionId={selectedId}
     onClose={() => setSelectedId(null)}
     onNavigate={handleNavigate}
   />
   ```
4. `handleNavigate`:
   ```tsx
   function handleNavigate(direction: 'prev' | 'next') {
     const idx = transactions.findIndex(t => t.id === selectedId);
     if (direction === 'prev' && idx > 0) setSelectedId(transactions[idx - 1].id);
     if (direction === 'next' && idx < transactions.length - 1) setSelectedId(transactions[idx + 1].id);
   }
   ```
