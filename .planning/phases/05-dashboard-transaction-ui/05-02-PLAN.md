**Route 1: GET /api/transactions** (paginated list)

Query params:
- `year` (optional) — filter by taxYear
- `type` (optional) — filter by canonicalType (e.g., "buy", "sell", "earn_interest")
- `coin` (optional) — filter by symbol (exact match)
- `from` (optional) — ISO date string, lower bound for tradedAt
- `to` (optional) — ISO date string, upper bound for tradedAt
- `search` (optional) — LIKE search on symbol and orderId
- `sortBy` (optional, default "tradedAt") — column to sort by: "tradedAt", "amount", "symbol", "canonicalType", "eurPrice"
- `sortDir` (optional, default "desc") — "asc" or "desc"
- `limit` (optional, default 50, max 200) — page size
- `offset` (optional, default 0) — pagination offset

Implementation:
1. Build conditions array using `and()`:
   ```typescript
   import { and, asc, desc, between, eq, like, or, sql, count } from 'drizzle-orm';
   ```
   - If `year`: `eq(transactions.taxYear, Number(year))`
   - If `type`: `eq(transactions.canonicalType, type)`
   - If `coin`: `eq(transactions.symbol, coin)`
   - If `from && to`: `between(transactions.tradedAt, from, to)`
   - If `search`: `or(like(transactions.symbol, '%'+search+'%'), like(transactions.orderId, '%'+search+'%'))`

2. Build sort expression:
   - For "amount" and "eurPrice": use `sql\`CAST(${col} AS REAL)\`` for numeric sort (TEXT columns!)
   - For other columns: use the column reference directly
   - Wrap with `asc()` or `desc()` based on sortDir

3. Run two queries:
   - Count query: `db.select({ count: count() }).from(transactions).where(and(...conditions)).get()`
   - Data query: `db.select({ /* TransactionListItem fields */ }).from(transactions).where(and(...conditions)).orderBy(...).limit(parsedLimit).offset(parsedOffset).all()`

4. Return `TransactionPageResponse`:
   ```json
   { "items": [...], "total": totalCount, "hasMore": offset + limit < totalCount, "offset": parsedOffset, "limit": parsedLimit }
   ```

**Route 2: GET /api/transactions/:id** (detail with FIFO lots)

1. Fetch the full transaction row by id. Return 404 if not found.

2. Query `lotConsumptions` joined to `fifoLots`:
   ```typescript
   const lots = db.select({
     lotId: lotConsumptions.lotId,
     amountConsumed: lotConsumptions.amountConsumed,
     costBasisEur: lotConsumptions.costBasisEur,
     proceedsEur: lotConsumptions.proceedsEur,
     gainLossEur: lotConsumptions.gainLossEur,
     feeEur: lotConsumptions.feeEur,
     heldDays: lotConsumptions.heldDays,
     haltefristMet: lotConsumptions.haltefristMet,
     acquiredAt: fifoLots.acquiredAt,
     costPerUnitEur: fifoLots.costPerUnitEur,
     symbol: fifoLots.symbol,
   })
   .from(lotConsumptions)
   .innerJoin(fifoLots, eq(lotConsumptions.lotId, fifoLots.id))
   .where(eq(lotConsumptions.sellTransactionId, id))
   .all();
   ```

3. Query `futuresPositions` where `transactionId = id` (for close transactions).

4. Query `earnIncome` where `transactionId = id`.

5. Compute `taxImpact`:
   - If lotConsumptions exist: bucket = 'private_sale', sum gainLossEur, check if all haltefristMet
   - If futuresPosition exists: bucket = 'futures_pnl', P&L = realizedPnlEur - feeEur
   - If earnIncome exists: bucket = 'staking_earn', total = eurValueAtReceipt
   - Otherwise: bucket = null, totalGainLossEur = "0", isTaxFree = true, reason = "No tax event"

6. Return `TransactionDetailResponse`.
