export interface YearSummaryResponse {

    totalLossesEur: MoneyString;
    netEur: MoneyString;
    taxableAmountEur: MoneyString;
    estimatedTaxEur: MoneyString;

  }>;

  totalTradeCount: number;
  totalTaxableEur: MoneyString;
  totalEstimatedTaxEur: MoneyString;

  // Chart data: monthly futures P&L (DASH-05, DASH-06)

  // Chart data: portfolio allocation from open lots (DASH-03)
  portfolioAllocation: Array<{ symbol: string; valueEur: MoneyString }>;
  // Chart data: year-over-year comparison (DASH-08)

    futuresNet: MoneyString;
    earnNet: MoneyString;

  <action>
Create `packages/backend/src/routes/summary.ts` with a `registerSummaryRoutes(app: Hono)` function. Follow the existing pattern from `engine.ts`.

**Route: GET /api/summary/:year**

1. Parse `year` from `c.req.param('year')` as integer. Return 400 if NaN.

2. **engineHasRun check:** Query `db.select().from(taxSummaries).limit(1).all()`. If empty array, return:
   ```json
   { "engineHasRun": false, "taxYear": year, "availableYears": [], ... all other fields as empty/zero }
   ```
   This distinguishes "engine never ran" from "engine ran, zero gains". Use `"0"` for MoneyString zeros, `0` for integer zeros, `[]` for array fields.

3. **Available years:** `db.selectDistinct({ year: taxSummaries.taxYear }).from(taxSummaries).all()` — map to `number[]`.

4. **Buckets:** Query `taxSummaries` where `eq(taxSummaries.taxYear, year)`. Map rows to the bucket shape from the response type. Each row has: `bucket`, `totalGainsEur`, `totalLossesEur`, `netEur`, `taxableAmountEur`, `estimatedTaxEur`, `tradeCount`.

5. **Aggregated KPIs:** Compute from buckets using `parseFloat()`:
   - `totalNetEur` = sum of all `netEur`
   - `totalTradeCount` = sum of all `tradeCount`
   - `totalTaxableEur` = sum of all `taxableAmountEur`
   - `totalEstimatedTaxEur` = sum of all `estimatedTaxEur`
   Convert back to string with `String(sum)`.

6. **Monthly spot (DASH-02, DASH-05):** JOIN `lotConsumptions` to `transactions` on `lotConsumptions.sellTransactionId = transactions.id`, filter by `lotConsumptions.taxYear = year`, group by `strftime('%Y-%m', transactions.tradedAt)`:
   ```typescript
   const monthlySpot = db.select({
     month: sql<string>`strftime('%Y-%m', ${transactions.tradedAt})`.as('month'),
     gains: sql<string>`CAST(SUM(CASE WHEN CAST(${lotConsumptions.gainLossEur} AS REAL) > 0 THEN CAST(${lotConsumptions.gainLossEur} AS REAL) ELSE 0 END) AS TEXT)`.as('gains'),
     losses: sql<string>`CAST(SUM(CASE WHEN CAST(${lotConsumptions.gainLossEur} AS REAL) < 0 THEN CAST(${lotConsumptions.gainLossEur} AS REAL) ELSE 0 END) AS TEXT)`.as('losses'),
   })
   .from(lotConsumptions)
   .innerJoin(transactions, eq(lotConsumptions.sellTransactionId, transactions.id))
   .where(eq(lotConsumptions.taxYear, year))
   .groupBy(sql`strftime('%Y-%m', ${transactions.tradedAt})`)
   .orderBy(sql`strftime('%Y-%m', ${transactions.tradedAt})`)
   .all();
   ```

7. **Monthly futures:** JOIN `futuresPositions` to `transactions` on `futuresPositions.transactionId = transactions.id`, filter by `futuresPositions.taxYear = year`, group by month:
   ```typescript
   const monthlyFutures = db.select({
     month: sql<string>`strftime('%Y-%m', ${transactions.tradedAt})`.as('month'),
     pnl: sql<string>`CAST(SUM(CAST(${futuresPositions.realizedPnlEur} AS REAL) - CAST(${futuresPositions.feeEur} AS REAL)) AS TEXT)`.as('pnl'),
   })
   .from(futuresPositions)
   .innerJoin(transactions, eq(futuresPositions.transactionId, transactions.id))
   .where(eq(futuresPositions.taxYear, year))
   .groupBy(sql`strftime('%Y-%m', ${transactions.tradedAt})`)
   .orderBy(sql`strftime('%Y-%m', ${transactions.tradedAt})`)
   .all();
   ```

8. **Per-coin gain/loss (DASH-04):** Group `lotConsumptions` by symbol from the lot's symbol via join to `fifoLots`:
   ```typescript
   const perCoinGainLoss = db.select({
     symbol: fifoLots.symbol,
     net: sql<string>`CAST(SUM(CAST(${lotConsumptions.gainLossEur} AS REAL)) AS TEXT)`.as('net'),
   })
   .from(lotConsumptions)
   .innerJoin(fifoLots, eq(lotConsumptions.lotId, fifoLots.id))
   .where(eq(lotConsumptions.taxYear, year))
   .groupBy(fifoLots.symbol)
   .orderBy(sql`SUM(CAST(${lotConsumptions.gainLossEur} AS REAL)) DESC`)
   .all();
   ```

9. **Portfolio allocation (DASH-03):** Open FIFO lots (remainingAmount > 0) grouped by symbol:
   ```typescript
   const portfolioAllocation = db.select({
     symbol: fifoLots.symbol,
     valueEur: sql<string>`CAST(SUM(CAST(${fifoLots.remainingAmount} AS REAL) * CAST(${fifoLots.costPerUnitEur} AS REAL)) AS TEXT)`.as('valueEur'),
   })
   .from(fifoLots)
   .where(sql`CAST(${fifoLots.remainingAmount} AS REAL) > 0`)
   .groupBy(fifoLots.symbol)
   .orderBy(sql`SUM(CAST(${fifoLots.remainingAmount} AS REAL) * CAST(${fifoLots.costPerUnitEur} AS REAL)) DESC`)
   .all();
   ```
   Note: Portfolio allocation is NOT filtered by year -- it shows current holdings across all years.

10. **Year-over-year (DASH-08):** Query all `taxSummaries` rows (no year filter), group by taxYear and pivot by bucket:
    ```typescript
    const allSummaries = db.select().from(taxSummaries).all();
    const yearOverYear = // group allSummaries by taxYear, extract spotNet/futuresNet/earnNet from matching bucket
    ```

11. **Freigrenze:** Extract from the `private_sale` bucket's `taxableAmountEur` for spot, and `staking_earn` bucket's `netEur` for earn. Use TAX_CONSTANTS.SPOT_FREIGRENZE_EUR and EARN_FREIGRENZE_EUR.
    The `spotNetForFreigrenze` should be the `private_sale` bucket's `netEur` (the pre-Freigrenze net gain). The `earnTotalForFreigrenze` should be the `staking_earn` bucket's `netEur`.

12. Return `c.json(response)`.
