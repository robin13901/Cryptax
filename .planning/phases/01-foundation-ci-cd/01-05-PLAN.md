  <name>Task 1: Install Three.js and add FloatingLines component</name>
  <files>
    packages/frontend/package.json

    packages/frontend/src/components/FloatingLines/FloatingLines.css
  </files>
  <action>
    Install Three.js (required by FloatingLines WebGL shader):
    ```
    npm install three -w packages/frontend
    npm install -D @types/three -w packages/frontend
    ```

    **Get the FloatingLines component source:**
    Try the shadcn CLI first:
    ```
    npx shadcn@latest add "https://www.reactbits.dev/backgrounds/floating-lines"
    ```
    If the CLI does not work or is not available, manually copy the component from the react-bits GitHub repository:
    https://github.com/DavidHDev/react-bits/tree/main/src/content/Backgrounds/FloatingLines

    Place the component at `packages/frontend/src/components/FloatingLines/FloatingLines.tsx`.

    If copying manually, the component should:
    - Accept props: `lineCount`, `animationSpeed`, `linesGradient` (array of hex strings), `mixBlendMode`, `className`, `style`, `enabledWaves` (top/middle/bottom booleans)
    - Use Three.js WebGL renderer with custom shaders for wave animation
    - Use ResizeObserver for responsive canvas sizing
    - Clean up WebGL context on unmount

    Configure for the Cryptax dark theme per CONTEXT.md decisions:
    - Dense and active (lineCount: 30-40, animationSpeed: 0.8-1.0)
    - Color palette: `['#0070F2', '#354A5F', '#0070F2', '#5fdc8a']` (blues + green accent)
    - `mixBlendMode: 'screen'` for blending over dark background

    **packages/frontend/src/components/FloatingLines/FloatingLines.css:**
    Positioning styles for the background layer:
    ```css
    .floating-lines-bg {
      position: fixed;
      inset: 0;
      z-index: 0;
      will-change: transform;
      contain: strict;
      pointer-events: none;
    }
    ```
  </action>
  <verify>
    1. `npx tsc -b` compiles frontend with Three.js types
    2. FloatingLines component file exists with WebGL rendering code
  </verify>
  <done>FloatingLines component installed and configured with Cryptax dark theme colors.</done>
</task>
