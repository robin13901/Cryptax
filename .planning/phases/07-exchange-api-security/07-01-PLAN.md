  <name>Task 2: Auth routes + JWT middleware</name>

  <action>
    1. Create `packages/backend/src/routes/auth.ts` with `registerAuthRoutes(app: Hono)`:

       - **GET /api/auth/status** — returns `{ hasPassword: boolean, authenticated: boolean }`. `hasPassword` from auth-store. `authenticated` checks if valid JWT cookie exists (try/catch around jwt verify). This endpoint is exempt from JWT middleware.

       - **POST /api/auth/setup** — accepts `{ password: string }`. If password already set, return 409. Validate password length >= 8 chars. Hash with `hashPassword()`, store with `setPasswordHash()`. Also generate a random `CREDENTIAL_MASTER_KEY` (32 bytes hex via `randomBytes(32).toString('hex')`) and store in app_settings under key `credential_master_key`. Return 201 `{ ok: true }`.

       - **POST /api/auth/login** — accepts `{ password: string }`. Get stored hash, verify with `verifyPassword()`. If invalid, return 401 `{ error: 'Falsches Passwort' }`. If valid, sign JWT with `sign({ sub: 'user', iat: Math.floor(Date.now() / 1000) }, JWT_SECRET)` using `hono/jwt`. Set cookie with `setCookie(c, 'session', token, { httpOnly: true, sameSite: 'Strict', path: '/' })` — NO maxAge, NO expires (session cookie per CONTEXT.md decision). Return 200 `{ ok: true }`.

       - **POST /api/auth/logout** — delete the session cookie with `deleteCookie(c, 'session', { path: '/' })`. Return 200 `{ ok: true }`.

       JWT_SECRET: Use `process.env.JWT_SECRET ?? crypto.randomBytes(32).toString('hex')` — generate a random secret on startup if not in env (persists for server lifetime).

    2. Update `packages/backend/src/index.ts`:

       - Import `jwt` from `hono/jwt` and `registerAuthRoutes` from `./routes/auth.js`
       - Add JWT middleware BEFORE all other route registrations:
         ```typescript
         app.use('/api/*', async (c, next) => {
           const path = new URL(c.req.url).pathname;
           if (path.startsWith('/api/auth/')) return next();
           try {
             return await jwt({ secret: JWT_SECRET, cookie: 'session' })(c, next);
           } catch {
             return c.json({ error: 'Unauthorized' }, 401);
           }
         });
         ```
       - Register auth routes FIRST: `registerAuthRoutes(app)` before other `register*Routes` calls
       - Export `JWT_SECRET` so auth routes can import it (or define in a shared config)
