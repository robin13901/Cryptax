  <files>

  <action>
    1. Create `packages/backend/src/auth/credential-cipher.ts`:

       - `encryptCredentials(plaintext: string, masterKey: string): string`
         - Generate 16-byte salt via `randomBytes(16)`
         - Generate 12-byte IV via `randomBytes(12)` (standard for GCM)
         - Derive 32-byte key via `pbkdf2Sync(masterKey, salt, 100_000, 32, 'sha256')`
         - Create cipher with `createCipheriv('aes-256-gcm', key, iv)`
         - Encrypt plaintext, get authTag
         - Return JSON string `{ iv: hex, salt: hex, authTag: hex, ciphertext: hex }`

       - `decryptCredentials(blobJson: string, masterKey: string): string`
         - Parse JSON blob, derive key from salt+masterKey same as encrypt
         - Create decipher, setAuthTag, decrypt and return plaintext
         - If authTag mismatch (wrong key), node:crypto throws — let it propagate

       - `getCredentialMasterKey(): string`
         - Read `credential_master_key` from app_settings table via auth-store
         - If not found, throw Error('No credential master key configured. Run setup first.')

    2. Create `packages/backend/src/auth/credential-cipher.test.ts`:
       - Test: encrypt then decrypt with same key returns original text
       - Test: decrypt with wrong key throws (authTag mismatch)
       - Test: encrypted blob has all 4 required fields (iv, salt, authTag, ciphertext)
       - Test: two encryptions of same plaintext produce different blobs (random IV/salt)
       - Test: encrypted blob does not contain plaintext (no substring match)

    3. Create `packages/shared/src/types/exchange.ts`:
       ```typescript

       }

       }
       ```
