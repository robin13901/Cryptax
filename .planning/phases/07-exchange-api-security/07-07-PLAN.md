       - **POST /api/exchanges/:id/sync** — Main sync endpoint
         - Parse connection id from params
         - Call `syncExchange(connectionId)` from sync-engine
         - Return 200 with SyncResult on success
         - Return 404 if connection not found
         - Return 500 with error message on sync failure (but DO NOT include credentials in error — just generic "Sync failed: {sanitized_message}")
         - Sanitize error message: strip any string that looks like an API key (remove strings longer than 20 chars that are alphanumeric-only — defensive measure)

       - **POST /api/exchanges/sync-all** — Sync all connections
         - Fetch all exchange_connections
         - For each, call syncExchange sequentially (not parallel — avoid rate limiting)
         - Aggregate results into array of SyncResult
         - Return 200 with `{ results: SyncResult[], totalImported: number, totalDuplicates: number }`

       - Test: POST /api/exchanges/:id/sync handles syncExchange error -> 500
       - Test: Error message is sanitized (no long alphanumeric strings leaked)

       - Test: POST /api/exchanges/sync-all aggregates results

       - Wire sync button: clicking "Synchronisieren" calls `onSync(connection.id)`
       - Show SyncProgress component when syncing or result available
       - Disable sync button while syncing
       - After sync completes, update lastSyncAt display

    5. Update `packages/frontend/src/components/Settings/SettingsTab.tsx`:
       - Implement sync handlers:
         - `handleSync(connectionId)`: POST /api/exchanges/:id/sync, update state with result, show toast
         - `handleSyncAll()`: POST /api/exchanges/sync-all, update states, show toast
       - Wire "Alle synchronisieren" button to handleSyncAll
       - Wire ExchangeCard onSync to handleSync
       - Track syncing state per connection: `Map<number, { syncing: boolean, result: SyncResult | null }>`
       - Use sonner toast for completion notifications:
         ```typescript
         import { toast } from 'sonner';
         toast.success('Sync abgeschlossen', {
           description: `${result.totalImported} neue Trades, ${result.totalDuplicates} Duplikate`,
         });
         ```
         Or for errors: `toast.error('Sync fehlgeschlagen', { description: error.message })`

    6. Update `packages/frontend/src/App.tsx`:
       - Add sonner Toaster provider at root level:
         ```tsx
         import { Toaster } from 'sonner';
         // In render, after FloatingLines:
         <Toaster position="bottom-right" richColors theme="dark" />
         ```
       - Add auto-sync on authenticated mount:
         ```typescript
         useEffect(() => {
           if (authState === 'authenticated') {
             // Auto-sync: fetch connections, trigger sync for each
             fetch('/api/exchanges')
               .then(r => r.json())
               .then((connections: ExchangeConnection[]) => {
                 if (connections.length > 0) {
                   fetch('/api/exchanges/sync-all', { method: 'POST' })
                     .then(r => r.json())
                     .then(result => {
                       if (result.totalImported > 0) {
                         toast.success('Auto-Sync abgeschlossen', {
                           description: `${result.totalImported} neue Trades importiert`,
                         });
                       }
                     })
                     .catch(() => {}); // Silent fail for auto-sync
                 }
               })
               .catch(() => {});
           }
         }, [authState]);
         ```
       - Auto-sync is fire-and-forget, silent on failure (per CONTEXT.md: auto-sync on app open)
