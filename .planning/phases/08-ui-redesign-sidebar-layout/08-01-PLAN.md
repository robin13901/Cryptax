Create `packages/frontend/src/components/Sidebar/Sidebar.tsx`:

**Props interface:**
```typescript
type TabId = 'dashboard' | 'transactions' | 'report' | 'settings';

interface SidebarProps {
  activeTab: TabId;
  onTabChange: (tab: TabId) => void;
  collapsed: boolean;
  onToggleCollapse: () => void;
}
```

**Navigation items array** (defined inside component or as const):
```typescript
const navItems: { id: TabId; label: string; icon: string }[] = [
  { id: 'dashboard', label: 'Dashboard', icon: 'dashboard-icon' },
  { id: 'transactions', label: 'Transaktionen', icon: 'transactions-icon' },
  { id: 'report', label: 'Steuerreport', icon: 'report-icon' },
  { id: 'settings', label: 'Einstellungen', icon: 'settings-icon' },
];
```

**Icons:** Use inline SVG icons for each nav item (NOT an icon library — keep zero new dependencies). Use simple, clean SVG paths:
- Dashboard: grid/4-squares icon (viewBox 0 0 24 24, four rounded squares)
- Transaktionen: list/receipt icon (horizontal lines with bullet)
- Steuerreport: document/file-text icon (paper with lines)
- Einstellungen: gear/cog icon (standard settings gear)

Each icon should be a small inline function or const returning JSX SVG, ~24x24 viewBox, stroke-based (not filled), stroke="currentColor", strokeWidth=1.5 or 2.

**Component structure:**
```tsx
<aside className={`sidebar ${collapsed ? 'sidebar--collapsed' : ''}`} aria-label="Navigation">
  {/* Branding area at top */}
  <div className="sidebar__brand">
    <span className="sidebar__logo">C</span>  {/* Single letter when collapsed */}
    {!collapsed && <span className="sidebar__brand-text">Cryptax</span>}
  </div>

  {/* Navigation items */}
  <nav className="sidebar__nav">
    {navItems.map(item => (
      <button
        key={item.id}
        type="button"
        className={`sidebar__nav-item ${activeTab === item.id ? 'sidebar__nav-item--active' : ''}`}
        onClick={() => onTabChange(item.id)}
        title={collapsed ? item.label : undefined}  {/* tooltip when collapsed */}
      >
        <span className="sidebar__nav-icon">{renderIcon(item.id)}</span>
        {!collapsed && <span className="sidebar__nav-label">{item.label}</span>}
      </button>
    ))}
  </nav>

  {/* Spacer pushes collapse button to bottom */}
  <div className="sidebar__spacer" />

  {/* Collapse/expand toggle at bottom */}
  <button
    type="button"
    className="sidebar__toggle"
    onClick={onToggleCollapse}
    aria-label={collapsed ? 'Sidebar ausklappen' : 'Sidebar einklappen'}
  >
    {/* Chevron SVG: points left when expanded, right when collapsed */}
    <svg>...</svg>
  </button>
</aside>
```

Export the TabId type from this file as well (re-export so App.tsx can import from Sidebar).

**IMPORTANT:** Do NOT import or use GlassSurface component for the sidebar — the sidebar needs its own glass styling applied directly via CSS (because GlassSurface has fixed width/height props that don't suit a full-height sidebar). Instead, replicate the glass aesthetic in Sidebar.css using the same CSS properties (backdrop-filter, background rgba, border, box-shadow).
