2. Create `packages/backend/src/engine/types.ts` with these engine-internal types (NOT shared types — these are for in-memory processing only):

```typescript
import type { Decimal } from '@cryptax/shared';
import type { BetterSQLite3Database } from 'drizzle-orm/better-sqlite3';
import type * as schema from '../db/schema.js';

export type Db = BetterSQLite3Database<typeof schema>;
```

Define these interfaces:

- `EngineTransaction`: Subset of transaction columns needed by engines: `id`, `orderId`, `exchange`, `sourceType` (SourceType), `canonicalType` (CanonicalType), `symbol`, `side`, `amount` (string), `price` (string), `fee` (string), `totalValue` (string), `tradedAt`, `taxYear`, `eurPrice` (string — non-null because null-price gate runs first).

- `InMemoryLot`: In-memory FIFO lot for processing: `id` (number, assigned after DB insert), `transactionId`, `symbol` (base asset, normalized), `originalAmount` (Decimal), `remainingAmount` (Decimal), `costPerUnitEur` (Decimal), `feeEur` (Decimal), `acquiredAt` (string), `taxYear` (number).

- `ConsumptionRecord`: Records one lot-to-sell pairing: `lotIndex` (number — position in lot array, mapped to DB id after insert), `sellTransactionId`, `amountConsumed` (Decimal), `costBasisEur` (Decimal), `proceedsEur` (Decimal), `gainLossEur` (Decimal), `feeEur` (Decimal — allocated sell fee portion), `heldDays` (number), `haltefristMet` (boolean), `taxYear` (number).

- `FifoEngineResult`: `lots: InMemoryLot[]`, `consumptions: ConsumptionRecord[]`, `sellsWithoutLots: Array<{ transactionId: number; symbol: string; amount: string }>`, `skipped: Array<{ transactionId: number; reason: string }>`.

- `SpotTaxResult`: Per-year spot tax aggregation: `taxYear`, `totalGainsEur` (string), `totalLossesEur` (string), `netGainEur` (string), `taxFreeGainEur` (string), `taxableAmountEur` (string), `totalFeesEur` (string), `tradeCount` (number).

- `FuturesPnlResult`: `positions: Array<{ transactionId: number; symbol: string; realizedPnlEur: string; feeEur: string; taxYear: number }>`, `skipped: Array<{ transactionId: number; reason: string }>`.

- `EarnIncomeResult`: `incomeRecords: Array<{ transactionId: number; symbol: string; amount: string; eurValueAtReceipt: string; receivedAt: string; taxYear: number }>`, `lotsCreated: InMemoryLot[]`, `skipped: Array<{ transactionId: number; reason: string }>`.

- `TaxCalculationResult`: `fifo: FifoEngineResult`, `spotTax: SpotTaxResult[]` (one per year), `futures: FuturesPnlResult`, `earn: EarnIncomeResult`, `summaries: Array<{ taxYear: number; bucket: string; totalGainsEur: string; totalLossesEur: string; netEur: string; taxableAmountEur: string; estimatedTaxEur: string; tradeCount: number }>`, `errors: Array<{ transactionId: number; reason: string }>`.

Export all types. Use `import type` for Decimal to keep it type-only where possible.

1. Create `packages/backend/src/engine/null-price-gate.ts`:

- Export interface `NullPriceError`: `{ transactionId: number; symbol: string; tradedAt: string; sourceType: string; canonicalType: string }`.

- Export function `checkNullPrices(db: Db): NullPriceError[]` that queries the `transactions` table for all rows where `eurPrice IS NULL`. Return array of `NullPriceError` objects. If array is empty, the gate passes. If non-empty, the engine must abort.

- Use Drizzle `isNull(transactions.eurPrice)` for the WHERE clause.

- Also filter out transactions that are skippable by the engine (canonicalType in ['transfer_in', 'transfer_out', 'earn_withdrawal', 'fee', 'unknown']) — these don't need EUR prices for tax calculation. Only check NULL prices on transactions that actually matter for tax computation: buy, sell, earn_interest, earn_deposit, futures_open_long, futures_open_short, futures_close_long, futures_close_short, futures_fee, futures_funding.

- Import Db type from `./types.js`.
