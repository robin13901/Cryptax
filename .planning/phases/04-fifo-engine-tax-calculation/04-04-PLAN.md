  <behavior>
The spot tax calculator takes consumption records from the FIFO engine and produces per-year tax aggregations.

**Function signature:**
`calculateSpotTax(consumptions: ConsumptionRecord[]): SpotTaxResult[]`

Pure function. Takes consumption records, returns one SpotTaxResult per tax year.

**Processing rules:**

1. Group consumptions by taxYear.

2. For each year, aggregate:
   - `taxFreeGainEur`: Sum of gainLossEur for consumptions where haltefristMet === true AND gainLossEur > 0
   - `totalGainsEur`: Sum of gainLossEur for consumptions where haltefristMet === false AND gainLossEur > 0 (taxable gains)
   - `totalLossesEur`: Sum of gainLossEur for consumptions where haltefristMet === false AND gainLossEur < 0 (taxable losses — store as negative)
   - `netGainEur`: totalGainsEur + totalLossesEur (losses are negative, so this subtracts)
   - `totalFeesEur`: Sum of feeEur across ALL consumptions for the year (informational)
   - `tradeCount`: Count of unique sellTransactionId values across consumptions for the year

3. Apply Freigrenze cliff to netGainEur:
   - If `netGainEur <= SPOT_FREIGRENZE_EUR` (1000): `taxableAmountEur = '0'`
   - If `netGainEur > SPOT_FREIGRENZE_EUR`: `taxableAmountEur = netGainEur` (entire amount is taxable, NOT netGain - 1000)
   - Note: Freigrenze is applied to the NET gain (gains minus losses) for the year, not per-trade.

4. Return one SpotTaxResult per year, sorted by taxYear ASC.

**Test cases (RED phase):**

- `aggregates gains and losses for a single year`: Multiple consumptions in 2024. Assert correct totals.
- `separates tax-free gains (Haltefrist met)`: Consumption with haltefristMet=true, gain=5000. Assert taxFreeGainEur=5000, not included in taxableAmountEur.
- `Haltefrist boundary: 365 days is NOT tax-free`: Consumption held 365 days. Assert haltefristMet=false in the consumption (this is from FIFO engine), and gain is included in taxable amount.
- `Haltefrist boundary: 366 days IS tax-free`: Consumption held 366 days. Assert haltefristMet=true, gain in taxFreeGainEur.
- `Freigrenze cliff: 999.99 EUR net gain is not taxable`: Net gain 999.99 EUR. Assert taxableAmountEur = '0'.
- `Freigrenze cliff: 1000.00 EUR net gain is not taxable`: Net gain exactly 1000.00 EUR. Assert taxableAmountEur = '0' (Freigrenze says <= 1000 is exempt).
- `Freigrenze cliff: 1000.01 EUR net gain is FULLY taxable`: Net gain 1000.01 EUR. Assert taxableAmountEur = '1000.01' (entire amount, NOT 0.01).
- `losses reduce net gain below Freigrenze`: Gain 1200, loss -300. Net = 900. Assert taxableAmountEur = '0' (below 1000).
- `losses reduce net gain but still above Freigrenze`: Gain 1500, loss -200. Net = 1300. Assert taxableAmountEur = '1300' (full amount).
- `handles multiple years`: Consumptions in 2024 and 2025. Assert two SpotTaxResult entries.
- `counts trades correctly`: 3 sell transactions, one consuming 2 lots. Assert tradeCount = 3 (unique sells).
- `handles empty consumption list`: No consumptions. Assert empty result array.
- `negative net gain (net loss) is not taxable`: Only losses. Assert taxableAmountEur = '0'.
  </behavior>
