  <behavior>
The FIFO engine processes spot transactions (buy/sell only) and produces lots + consumption records.

**Function signature:**
`runFifoEngine(transactions: EngineTransaction[]): FifoEngineResult`

Pure function — no DB access. Takes pre-sorted transactions, returns lots and consumptions.

**Processing rules:**
1. Sort transactions by `tradedAt` ASC. Tiebreak: buys before sells at same timestamp. Sort order: buy=0, sell=1 (ascending).

2. For each `buy` (canonicalType === 'buy'):
   - Normalize symbol to base asset using `parseSymbol(symbol, sourceType).base`
   - Create InMemoryLot: `originalAmount = toDecimal(tx.amount)` (gross), `remainingAmount = originalAmount`, `costPerUnitEur = (toDecimal(tx.totalValue) + toDecimal(tx.fee)) / toDecimal(tx.amount)`, `feeEur = toDecimal(tx.fee)`, `acquiredAt = tx.tradedAt`, `taxYear = tx.taxYear`
   - Non-EUR fees: fee is already in EUR because eurPrice was resolved in Phase 3. The `fee` field in spot_tx is in the coin's quote currency. For cost basis calculation, use `(toDecimal(tx.eurPrice).times(toDecimal(tx.amount)).plus(toDecimal(tx.fee)))` as total cost when fee is in EUR, OR compute as `toDecimal(tx.eurPrice).times(toDecimal(tx.amount))` for totalValue and add fee separately. Use the eurPrice field: costPerUnit = eurPrice (per unit EUR price from Phase 3). costBasisEur = eurPrice * amount. feeEur = fee field value (need to handle non-EUR: if fee is not 0 and transaction has eurPrice, convert fee using eurPrice or treat fee as already accounted for in totalValue).
   - SIMPLIFICATION: The `totalValue` field from normalized transactions already represents total EUR value when eurPrice is set. Cost basis = `toDecimal(tx.eurPrice).times(toDecimal(tx.amount))`. Fee in EUR = fee * eurPrice if fee is in coin units, or fee directly if in EUR. Since fee treatment varies by source type, use: `feeEur = toDecimal(tx.fee).times(toDecimal(tx.eurPrice))` for spot_tx (fee is in coin), and `toDecimal(tx.fee)` for spot_order (fee is in quote currency). Actually, the safest approach: compute costBasisEur = eurPrice * amount, and feeEur from the fee field converted to EUR. costPerUnitEur = (costBasisEur + feeEur) / amount.

3. For each `sell` (canonicalType === 'sell'):
   - Normalize symbol to base asset
   - Find lots for that base asset, ordered by acquiredAt ASC (FIFO)
   - Consume lots: iterate oldest-first, consume min(remaining, sellRemaining) from each lot
   - For each consumption: compute costBasis = consumed * lot.costPerUnitEur, proceeds = consumed * toDecimal(sellTx.eurPrice), allocatedSellFee = consumed / sellAmount * totalSellFee, gainLoss = proceeds - costBasis - allocatedSellFee
   - Compute heldDays using differenceInCalendarDays(sellDate, lot.acquiredAt)
   - Compute haltefristMet using heldDays >= TAX_CONSTANTS.HALTEFRIST_DAYS (366)
   - If sell cannot be fully consumed (not enough lots), add to sellsWithoutLots

4. Only process canonicalType 'buy' and 'sell'. Skip all others and add to skipped array.

**Test cases (RED phase — write these first):**

- `creates a lot from a buy transaction`: 1 BTC buy at 50000 EUR. Assert 1 lot created with correct amounts.
- `consumes a lot on sell (full consumption)`: Buy 1 BTC, sell 1 BTC. Assert lot.remainingAmount = 0, 1 consumption record.
- `consumes lots in FIFO order`: Buy 0.5 BTC at 40000, buy 0.5 BTC at 60000, sell 0.5 BTC. Assert first lot consumed (40000 cost basis), second lot untouched.
- `handles partial lot split across two lots`: Buy 0.3 BTC, buy 0.7 BTC, sell 0.5 BTC. Assert first lot fully consumed (0.3), second lot partially consumed (0.2), second lot remaining = 0.5.
- `flags sell without matching lots`: Sell 1 BTC with no prior buys. Assert sellsWithoutLots contains the transaction.
- `flags sell that exceeds available lots`: Buy 0.5 BTC, sell 1.0 BTC. Assert partial consumption of 0.5 + error in sellsWithoutLots for the remaining 0.5.
- `normalizes symbols from different source types`: Buy BTC via spot_tx (symbol "BTC"), sell BTC via spot_order (symbol "BTC/EUR"). Assert they match the same lot pool.
- `processes buys before sells at same timestamp`: Buy and sell at identical timestamp. Assert buy creates lot before sell consumes it.
- `computes correct cost basis with fees`: Buy 1 BTC at eurPrice=50000, fee=0.001 BTC. Assert costPerUnitEur includes fee.
- `computes correct held days and Haltefrist`: Buy at 2024-01-01, sell at 2025-01-02 (366 days). Assert haltefristMet = true. Buy at 2024-01-01, sell at 2025-01-01 (365 days). Assert haltefristMet = false.
- `allocates sell fees proportionally across consumed lots`: Buy 0.3 BTC, buy 0.7 BTC, sell 1.0 BTC with fee. Assert fee is split proportionally.
- `keeps separate lot pools per asset`: Buy 1 BTC and 10 ETH. Sell 1 BTC. Assert ETH lots untouched.
- `skips non-buy/sell transactions`: Pass futures_open_long and transfer_in. Assert they appear in skipped array.
  </behavior>
  <implementation>
Export `runFifoEngine(transactions: EngineTransaction[]): FifoEngineResult`.

Internal structure:
1. Sort transactions (copy array, don't mutate input)
2. Build lot pool: `Map<string, InMemoryLot[]>` keyed by base asset
3. Process each transaction in order
4. For buys: create lot, push to pool
5. For sells: consume from pool in FIFO order, track consumptions
6. Return result with lots, consumptions, errors

Use `parseSymbol(tx.symbol, tx.sourceType as SourceType).base` for normalization.
Use `differenceInCalendarDays` from date-fns for held days.
Use `TAX_CONSTANTS.HALTEFRIST_DAYS` (366) for Haltefrist check.
All arithmetic via `toDecimal()` / Decimal operations.

Fee handling for buy-side:
- Spot_tx fee is in coin units. feeEur = toDecimal(tx.fee).times(toDecimal(tx.eurPrice)). This converts the coin-denominated fee to EUR.
- Spot_order fee: check the source. For spot_order, the fee field from the CSV is already in quote currency. If quote is EUR, fee is already EUR. If quote is USDT, fee needs conversion. Safest: always multiply fee by eurPrice for consistency, since eurPrice is per-unit of the base asset. Actually this is wrong for fees not denominated in base asset.
- DECISION: Use a simpler approach. The fee field in the normalized transaction is already in its native denomination. For cost basis calculation: `costBasisEur = toDecimal(tx.eurPrice).times(toDecimal(tx.amount))`. The fee is separate. For the FIFO lot, store `feeEur` as the fee converted to EUR. The conversion: if fee is non-zero, `feeEur = toDecimal(tx.fee).times(toDecimal(tx.eurPrice))` — this works for spot_tx where fee is in base asset (fee in BTC * EUR/BTC = EUR). For spot_order where fee might be in quote currency, this approximation is acceptable since fees are small. Record `costPerUnitEur = costBasisEur.plus(feeEur).div(toDecimal(tx.amount))`.
