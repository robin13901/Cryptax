# Plan 02-08: Import API + UI

## Objective

Build the database insert layer, import orchestrator, Hono API endpoints, and the React drag-and-drop UI that ties the entire CSV import pipeline together. This is the integration layer that makes the pipeline usable.

Purpose: This plan connects all the parser and normalizer modules (02-02 through 02-07) to the database and the user interface. After this plan, a user can actually import CSV files through the browser.

Output: Working end-to-end import flow: drag CSV -> parse -> normalize -> deduplicate -> store -> show summary.

  <action>
    **insert.ts:**
    1. Export `batchInsert(rows: (typeof transactions.$inferInsert)[], batchId: number): { inserted: number; duplicates: number }`:
       - Chunk rows into groups of 200 using a `chunkArray` helper
       - Wrap all chunks in a single `db.transaction()` call
       - For each chunk: `tx.insert(transactions).values(chunk).onConflictDoNothing().run()`
       - Count `result.changes` across all chunks for `inserted`
       - `duplicates = rows.length - inserted`
    2. Import `db` from `'../db/client.js'` and `transactions` from `'../db/schema.js'`

    **insert.test.ts:**
    - Test inserting 3 rows -> inserted: 3, duplicates: 0
    - Test inserting same 3 rows again -> inserted: 0, duplicates: 3 (dedup by unique constraint)
    - Test chunking: insert 250 rows -> all inserted (tests the chunking logic)
    - Use DB_PATH=':memory:' or temp file for test isolation
    - Run migration before tests (use drizzle migrate or manual CREATE TABLE)
    - Note: The test needs to set up the schema. Use `sqlite.exec(fs.readFileSync('drizzle/0000_initial.sql'))` and the 0001 migration.

    **orchestrator.ts:**
    1. Export `importCSVFile(fileText: string, filename: string): PerFileResult`:
       - Call `parseRawCSV(fileText)` -> get `{ format, rows }`
       - Route to correct parser based on format:
         - 'spot_tx' -> `parseSpotTx(rows, filename)`
         - 'futures_tx' -> `parseFuturesTx(rows, filename)`
         - 'spot_order' -> `parseSpotOrder(rows, filename)`
         - 'futures_order' -> `parseFuturesOrder(rows, filename)`
         - 'earn' -> `parseEarn(rows, filename)`
       - Normalize each parsed row: `normalizeToTransaction(parsedRow, format, filename, originalCsvRow)`
         - Need to pair parsed rows with their original csv-parse output rows for checksum
       - Create import_batches record FIRST:
         ```typescript
         const [batch] = db.insert(importBatches).values({
           filename,
           sourceType: format,
           totalRows: rows.length,
           importedCount: 0,
           duplicatesCount: 0,
           errorsCount: parserErrors.length,
           importedAt: new Date().toISOString(),
         }).returning();
         ```
       - Set `batchId` on all normalized transaction rows: `row.batchId = batch.id`
       - Call `batchInsert(normalizedRows, batch.id)`
       - Update the import_batches record with actual counts:
         ```typescript
         db.update(importBatches).set({
           importedCount: insertResult.inserted,
           duplicatesCount: insertResult.duplicates,
         }).where(eq(importBatches.id, batch.id)).run();
         ```
       - Return `PerFileResult` with all counts

    2. Handle errors gracefully: if `detectFormat` throws, return a PerFileResult with 0 imported and the error message

    **orchestrator.test.ts:**
    - Test with a synthetic spot_tx CSV string (3 Buy rows) -> format detected, rows parsed, normalized, inserted
    - Test with unknown format -> returns error in PerFileResult, no crash
    - Test duplicate detection: import same CSV twice -> second import has 0 imported, N duplicates
    - Use in-memory DB for test isolation

    **routes/import.ts:**
    1. Export `registerImportRoutes(app: Hono)` following the health.ts pattern
    2. `POST /api/import/csv`:
       - `const formData = await c.req.formData()`
       - `const files = formData.getAll('files') as File[]`
       - For each file: `const text = await file.text(); const result = importCSVFile(text, file.name)`
       - Aggregate results into `ImportResponse` shape
       - Return `c.json(response, 200)`
    3. `GET /api/import/batches`:
       - Query all import_batches ordered by importedAt DESC
       - Return `c.json(batches)`
    4. `DELETE /api/import/batches/:id`:
       - Delete all transactions with matching batch_id
       - Delete the import_batches record
       - Return `c.json({ deleted: true, batchId: id })`
       - Use a transaction for atomicity

    **routes/import.test.ts:**
    - Test POST /api/import/csv with FormData containing a small CSV -> 200, correct summary
    - Test GET /api/import/batches -> returns array of batches
    - Test DELETE /api/import/batches/:id -> deletes batch and its transactions
    - Use in-memory DB for test isolation

    **Update index.ts:**
    Add import route registration:
    ```typescript

    // ... after registerHealthRoutes(app);
    registerImportRoutes(app);
    ```


    Run `npx biome format --write` on all new files.
