# Plan 02-06: On-chain Earn Parser (TDD)

## Objective

Build a parser for Bitget on-chain earn CSVs using TDD. This is the simplest format (8 columns) with one key difference: the Reference column has no tab prefix.

Purpose: On-chain earn records represent staking deposits. They have a unique structure with 'Interest coin' and 'Handling fee' columns not found in other formats.

Output: `parseEarn()` function with comprehensive tests.

## Context

@.planning/phases/02-csv-import-pipeline/02-RESEARCH.md (Format 4 section, earn field mapping)
@packages/shared/src/types/transaction.ts

## Feature

<feature>
  <name>On-chain Earn CSV Parser</name>
  <files>
    packages/backend/src/import/parsers/earn.ts
    packages/backend/src/import/parsers/earn.test.ts
  </files>
  <behavior>
    The `parseEarn(rows: Record<string, string>[], filename: string)` function accepts pre-parsed CSV rows and returns `{ transactions: ParsedEarn[], errors: ImportFileError[] }`.

    ParsedEarn shape:
    ```typescript
    interface ParsedEarn {
      reference: string;      // from 'Reference' column (NO tab prefix, clean numeric)
      startTime: string;      // from 'Start time' column
      coin: string;           // from 'Coin' column (staked asset)
      rawType: string;        // from 'Type' column (e.g., 'Staking')
      interestCoin: string;   // from 'Interest coin' column (asset received as interest)
      amount: string;         // from 'Amount' column (always positive)
      handlingFee: string;    // from 'Handling fee' column
      status: string;         // from 'Status' column (e.g., 'Staked')
      sourceFile: string;
    }
    ```

    Headers: `Reference,Start time,Coin,Type,Interest coin,Amount,Handling fee,Status`

    Test cases:
    - Staking row -> all fields mapped, reference is clean numeric (no tab)
    - Interest coin differs from Coin -> both captured separately
    - Amount is positive -> no sign handling needed
    - Handling fee is '0' -> captured as '0'
    - Row with missing Reference -> error
    - Row with missing Start time -> error
    - Row with missing Amount -> error
    - Multiple valid rows
    - Status 'Staked' preserved
  </behavior>
  <implementation>
    1. Create `packages/backend/src/import/parsers/earn.ts`
    2. Define `ParsedEarn` interface and `parseEarn` function
    3. Normalize column keys to lowercase
    4. Note: column keys include 'start time' (with space), 'interest coin' (with space), 'handling fee' (with space)
    5. Validate required fields: 'reference', 'start time', 'amount', 'type'
    6. Reference is the orderId equivalent — no tab stripping needed (already clean)
    7. Use 'interest coin' for the received asset symbol, 'coin' for the staked asset
  </implementation>
</feature>
